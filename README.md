# MAZER

HTML5 canvas maze. Open `index.html` in a browser.

Full-window canvas. 20px cells. Grid size is the largest odd width and height that fit; leftover pixels sit as a margin.

Generation grows winding branches from the runner, then links leftover rooms. After that the runner is a free-moving circle. Arrow keys / WASD. `R` rebuilds. Touching the goal builds a new maze.
